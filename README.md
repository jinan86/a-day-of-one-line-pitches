Entry for the make.fun competition [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3): one sentence that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

## The pitch

> You've got the idea and I've got the link — drop your first app idea into make.fun, let an AI agent build it, and if you don't like the first version, you've lost nothing but a sentence.

## How it works

`main.py` (Python 3.13, standard library only, no network, no clock, no randomness) writes the sentence above, exactly, to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```
